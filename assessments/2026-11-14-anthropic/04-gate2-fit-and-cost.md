### Cost worksheet
- Model + published price (source, access date): Claude Sonnet 5.5, $2 input / $10 output per MTok; Claude Haiku 5.5, $0.10 input / $0.50 output per MTok for prompts up to 100,000 tokens ($0.50 / $2.50 above). Pricing, Claude Platform Docs, rechecked Sat Nov 14, 2026: unchanged from the prep pack's Nov 13 figures. Batch prices are 50% of these; US-only inference (`inference_geo: "us"`) multiplies all categories by 1.1.
- Assumed tokens per ticket (assumptions, set Sat Nov 14, 2026; the current-generation tokenizer runs about 30% denser than its predecessor per the pricing page, which sits inside these round numbers' error bars): summarizer leg in ≈ 750 (ticket thread ≈ 600 + instructions ≈ 150), out ≈ 120 (structured summary). Drafter leg in ≈ 1,200 (ticket ≈ 600 + summary ≈ 120 + template and policy context ≈ 480), out ≈ 250 (draft reply).
- **Cost per ticket:** summarizer leg $0.000135 + drafter leg $0.0049 ≈ **$0.0050, about half a cent** (estimate from the assumptions above). **Cost per day at 2,000 tickets: ≈ $10.07** (≈ $302 per 30-day month; ≈ $11.08/day with US-only inference). Sensitivity: at twice the assumed tokens, ≈ $20/day. Prompt caching is unmodeled and would lower the figure (Sonnet 5.5 cache reads price at 0.05x base input). Running the summarizer leg on Batch would save ≈ $0.07/day and is excluded on retention grounds regardless (§1).
- Method anchor: the harness's 100-run experiment cost $0.14 total in API calls (whitepaper v0.3), cited as proof the measurement method is cheap. It is NOT a per-ticket cost; a ticket's token profile differs from a harness run's. Cost per ticket is built only from the published prices and assumed tokens above.
